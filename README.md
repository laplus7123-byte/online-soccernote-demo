# Online Soccer Note — 操作デモ

静的なデザイン・操作プレビューです。実サービスや決済サイトではありません。

## GitHub Pages

このフォルダーの内容を専用リポジトリのルートへ配置します。Settings → Pages → Deploy from a branch → main / (root) を選択してください。`.nojekyll` も含めて配置します。

入口のindex.htmlから選手、保護者、運営の画面へ進めます。リポジトリ名を含むサブパスでも動く相対URLを使用しています。

## 機能の範囲

- テーマ・ふりかえり・タスク・カレンダー・画像取り込みのサンプル・3言語切替を操作できます。
- ログイン、契約管理、決済は架空データを使った操作見本です。外部認証、会員DB、決済には接続していません。
- AI認識、実動画生成、サーバー保存、メール・通知送信は実行しません。
- 入力内容はsessionStorage、表示言語はlocalStorageを使用。他端末同期はありません。
- 元アプリのPHP、DB、認証情報、引き継ぎ資料、検証スクリーンショットは含めていません。
- 管理画面も公開レビュー用の架空データです。本番の認証・権限制御として使用しないでください。
- `noindex` は検索掲載を抑える指定であり、閲覧制限ではありません。Pagesのサイト・公開リポジトリは誰でも閲覧できます。

本番で利用するには、既存のPHPアプリと認証・DB・決済への組み込みが必要です。
